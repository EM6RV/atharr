# متجر أثر ATHAR — طريقة التشغيل

الموقع يشتغل على خدمتين مجانيتين، بدون بطاقة بنكية وبدون أي سيرفر:

- **Supabase**: قاعدة البيانات (العطور والطلبات والإعدادات)، وتخزين صور العطور، وتسجيل دخول لوحة التحكم.
- **GitHub Pages**: استضافة الموقع نفسه، على حساب GitHub اللي عندك.

## محتويات المجلد

| الملف | وش هو |
|---|---|
| `index.html` | واجهة المتجر اللي يشوفها الزبون |
| `admin.html` | لوحة التحكم (الطلبات، العطور، الإعدادات) |
| `config.js` | رابط ومفتاح Supabase، **لازم تعبّيه** |
| `supabase.sql` | إعداد قاعدة البيانات، تشغّله مرة وحدة |
| `assets/` | الشعار وملفات البرمجة |

---

## الخطوة 1: إنشاء قاعدة البيانات في Supabase

1. ادخل [supabase.com](https://supabase.com)، واضغط **Start your project**، وسجّل بحساب GitHub.
2. اضغط **New project**:
   - Name: `athar`
   - Database Password: اكتب كلمة سر قوية واحفظها عندك
   - Region: اختر **Frankfurt (eu-central-1)** لأنها الأقرب لليبيا
3. انتظر دقيقة أو دقيقتين لين يجهز المشروع.
4. من القائمة الجانبية افتح **SQL Editor**، ثم **New query**. انسخ محتوى ملف `supabase.sql` كامل، والصقه، واضغط **Run**. المفروض يطلع لك `Success`.

## الخطوة 2: إنشاء حساب المدير (أنت)

1. من القائمة افتح **Authentication**، ثم **Users**، ثم **Add user**، ثم **Create new user**.
2. اكتب إيميلك وكلمة سر، وفعّل **Auto Confirm User**، واضغط Create.
3. ارجع لـ **SQL Editor** وشغّل هذا السطر بعد ما تغيّر الإيميل لإيميلك:
   ```sql
   insert into public.admins (user_id) select id from auth.users where email = 'you@example.com';
   ```
4. **مهم للأمان:** افتح **Authentication**، ثم **Sign In / Providers**، ثم **Email**، وطفّي **Allow new users to sign up**. كذا ما أحد غيرك يقدر يسوي حساب.

## الخطوة 3: ربط الموقع بقاعدة البيانات

1. في Supabase افتح **Project Settings**، ثم **API** (أو **Data API**).
2. انسخ **Project URL** و **anon public key**.
3. افتح ملف `config.js` بأي محرر نصوص (مثل Notepad) وحطهم كذا:
   ```js
   SUPABASE_URL: 'https://xxxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbGciOi...'
   ```
   > مفتاح **anon** مسموح يكون ظاهر في الموقع، والحماية مسوّاة في قاعدة البيانات. أما مفتاح **service_role** فلا تحطه أبداً في أي ملف.

## الخطوة 4: رفع الموقع على GitHub Pages

1. ادخل GitHub، واضغط **New repository**، وسمّه `athar`، وخلّه **Public**، ثم Create.
2. اضغط **uploading an existing file**، واسحب **كل الملفات والمجلدات** (`index.html` و `admin.html` و `config.js` و `supabase.sql` ومجلد `assets`)، ثم **Commit changes**.
3. افتح **Settings** في الريبو، ثم **Pages**. تحت Source اختر **Deploy from a branch**، والفرع **main**، والمجلد **/ (root)**، ثم **Save**.
4. بعد دقيقة أو دقيقتين يطلع لك رابط الموقع:
   `https://اسم-حسابك.github.io/athar/`
5. لوحة التحكم على نفس الرابط مع `admin.html` في آخره:
   `https://اسم-حسابك.github.io/athar/admin.html`

## الخطوة 5: جهّز المتجر من لوحة التحكم

1. ادخل لوحة التحكم بإيميلك وكلمة السر.
2. من **الإعدادات**: حط رقم واتساب الطلبات، وعدّل أسعار التوصيل لكل مدينة.
3. من **العطور**: عدّل العطور التجريبية أو احذفها، وأضف عطورك الحقيقية بصورها وأسعارها وأحجامها.

---

## كيف يشتغل الطلب

1. الزبون يختار العطور ويكتب اسمه ورقمه ومدينته.
2. الطلب **ينحفظ في لوحة التحكم مباشرة** برقم مثل `ATH-1001`. الأسعار تنحسب من قاعدة البيانات، فما أحد يقدر يغيّرها من المتصفح.
3. يطلع للزبون زر يفتح واتساب برسالة الطلب جاهزة يرسلها لك.
4. أنت تغيّر حالة الطلب من اللوحة: جديد، مؤكد، مع المندوب، تم التسليم، ملغي.

## ملاحظات مهمة

- **Supabase المجاني** يعطيك 500 ميجا للبيانات و1 جيجا للصور، وهذا يكفي آلاف الطلبات ومئات العطور. الصور تتصغّر تلقائياً قبل الرفع.
- **لو ما دخل أحد على الموقع 7 أيام متواصلة**، Supabase يوقف المشروع مؤقتاً. ترجعه بضغطة **Restore** من لوحة Supabase. مع زيارات يومية ما راح يوقف.
- **دومين خاص** (مثل athar.ly): من Settings ثم Pages ثم Custom domain في GitHub.
- **أي تعديل على الملفات:** ارفع الملف المعدّل على GitHub بنفس الاسم، والموقع يتحدث خلال دقيقة.
